# bank-liquidity

Commercial Bank Liquidity &amp; Interest Rate Risk in the Banking Book (IRRBB)

Commercial Bank Liquidity & Interest Rate Risk in the Banking Book (IRRBB)
The Concept: This is the ultimate "Regulator" project. Following the 2023 banking turmoil, liquidity risk is paramount. You would build a model that analyzes a bank's asset-liability mismatch. You'll simulate deposit flight scenarios and calculate Net Interest Margin (NIM) sensitivity using duration and convexity gaps under shifting yield curves.

Data Sources (Secondary):

FFIEC Central Data Repository / FDIC Call Reports: Publicly available quarter-by-quarter balance sheets for every regulated bank in the US.

FRED: For Treasury yield curve data (Daily yield curve rates).

Why it looks "Forward-Thinking": It addresses the exact, real-world issues current FIRREA agencies are actively regulating. It shows you can read a bank balance sheet and apply advanced stochastic interest rate simulations (like a Vasicek or Cox-Ingersoll-Ross model) to it.
